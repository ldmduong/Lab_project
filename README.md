# Lab Project (`Lab_project`)

Mô tả ngắn gọn về mục tiêu, đề tài hoặc nội dung nghiên cứu của đồ án/phòng thí nghiệm này.

## 🛠️ Công nghệ & Công cụ sử dụng
* Ngôn ngữ lập trình: Python / C++ / Java / ...
* Thư viện / Framework: TensorFlow / PyTorch / React / ...
* Công cụ hỗ trợ: Git, Docker, VS Code, ...
